## The entry

A tiny TypeScript program (`main.ts`) that writes a single roast line — at most
200 characters — to `/output/entry.txt`:

> My fridge beeps at 3 a.m. like a smoke alarm with abandonment issues — all because I opened it once after midnight and didn't say thank you.

Why this line fits the judging criteria:

1. **Roasts a fridge** — the whole line is about my own fridge.
2. **Specific, recognisable detail** — the door-open alarm beeping at 3 a.m.,
   something every fridge owner has heard.
3. **Twist in the last few words** — "and didn't say thank you" reframes the
   beeping as the fridge demanding manners.
4. **Reads cleanly aloud** — one sentence, one line, no setup that needs a
   second sentence.
5. **Fresh** — the fridge as a needy appliance with abandonment issues, not
   the worn-out "it's cold in here" joke.

## Run it

```sh
node main.ts
```

Requires Node 22 or later. The program is deterministic, uses no network,
no secrets and no environment variables, and writes the entry to
`/output/entry.txt` (override with `OUTPUT_DIR`).
